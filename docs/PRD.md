## 1. 한 장 요약

| 항목 | 내용 |
| --- | --- |
| 서비스 | 어깨PIZZA ("어깨 펴자"의 말장난) |
| 문제 | 오래 앉거나 같은 자세로 일하는 사람이 늘고 있다(8시간 이상 앉는 성인 비율 46.7% → 63.0%) [E1]. 그런데 고정 간격 알림은 시간이 지나면 무시된다 [E7][E8] |
| 대상 | 1차: 하루 대부분을 의자에서 보내는 지식노동자. 2차: 1인 사업자 |
| 해결 | 알림 받을 시간대를 피자 한 판으로 만든다. 3~8조각으로 나누고, 조각 시각에 알림 메일이 간다. 들어오면 내 컨디션(피자 종류)과 오늘 날씨에 맞는 스트레칭을 보여 주고, 먹은 조각을 기록한다 |
| 무료 API | Open-Meteo (메인: 날씨·대기질로 화면 효과와 추천 조정) + API Ninjas Exercises (보조: 추가 동작) + free-exercise-db 기반 로컬 데이터 |
| 검증 전략 | Streamlit 웹과 알림 메일로 수요를 먼저 확인한다. 실제 서비스는 앱(로컬 알림)으로 출시할 예정이다 |
| 제외 | 챗봇, OpenAI 등 생성형 AI는 MVP에서 쓰지 않는다 |

## 2. 시장 문제정의

**문제 문장**: 하루 대부분을 같은 자세로 일하는 직장인(누가)은 몸이 뻐근해도 일에 몰입하거나, 무엇을 할지 고르는 사이(상황)에 스트레칭을 하루 여러 번 실천하지 못한다(무엇을 못 해서). 그 결과 불편과 피로를 하루 끝까지 쌓아 둔다(어떤 손해).

| 사실 | 수치 | 근거 |
| --- | --- | --- |
| 오래 앉는 사람이 늘고 있다 | 하루 8시간 이상 앉는 성인 46.7%(2014) → 63.0%(2021) | [E1] 1차 |
| 하루 평균 좌식 시간이 늘었다 | 8.3시간(2018) → 9시간(2023) | [E3] 2차, 원문 확인 필요 |
| 움직이는 사람은 줄었다 | 유산소 신체활동 실천율 49.5%(2025), 전년보다 남녀 모두 감소 | [E2] 1차 |
| 불편의 규모가 크다 | 어깨병변 환자 약 242.6만 명(2022) | [E4] 2차. 좌식과 인과관계가 있다고 주장하지 않음 |
| 가볍게 움직이는 것만으로도 권장된다 | WHO: 앉아 있는 시간을 줄이고, 강도와 상관없이 몸을 움직이면 건강에 이롭다 | [E5] 1차 |
| 알림의 효과는 시간이 지나면 떨어진다 | 매시간 알림 실험에서 참여 횟수가 주 12회 → 주 3회로 감소 | [E7] 학회 초록 |
| 알림만으로는 습관이 되지 않는다 | 리마인더는 반복은 돕지만 습관 형성은 방해하고, 사건 기반 신호가 자동화를 높인다 | [E8] |

**기회**: 알림을 열 때마다 "오늘의 내 상태"를 묻고 매번 다른 동작을 주면, 알림이 반복이 아니라 새로운 일이 된다. 피자를 완성해 가는 시각적 보상이 이 점을 더 강화한다. (가설)

**한계**: 최근 3년 안의 국내 직장인 "근무 중 스트레칭 실천" 설문은 찾지 못했다. 이 부분은 인터뷰와 웹 수요 검증으로 채운다.

## 3. 경쟁 서비스와 차별점

| 서비스 | 알림 방식 | 맞춤화 | 한계 |
| --- | --- | --- | --- |
| Apple·Galaxy 워치 | 오래 움직이지 않으면 알림(삼성은 50분) | 없음 | "일어나라"고만 하고 무엇을 할지는 알려주지 않음 |
| Wakeout | "좋은 순간"에 알림 | 시간대, 원하는 기분 | 유료 구독 |
| Bend, STRETCHIT | 알림이 없거나 하루 1회 | 목표·부위별 루틴 | 하루 여러 번 짧게 하는 구조가 아님 |
| Stretch Reminder AI | 선택형 일일 알림 | AI 루틴과 채팅 | AI 자체로는 차별점이 되지 않음 |

**어깨PIZZA의 차별점**
- 내 활동 시간이 곧 피자 한 판이다. 알림 시간표를 설명할 필요 없이 그림으로 보인다.
- 조각마다 그때의 컨디션을 고른다. 하루가 끝나면 "오늘 완성된 피자"가 남는다.
- 말장난 이름("어깨 펴자")이라 기억하기 쉽다.

## 7. 서비스 컨셉: 피자 메타포

**한 줄**: 조각 내어 맛보는 스트레칭 한판 피자

**카피 (랜딩)**
> 매일매일 차갑게 식어 굳어버리는 당신의 어깨 피자,
> 식으면 섭섭하잖아요.
> 오늘은 따끈따끈하게 맛있는 피자를 구워봐요!

**비주얼**: 피자가게 같은 이미지, 일러스트, 손글씨 느낌. 날씨에 따라 화면 효과(맑음 햇살, 비, 눈, 안개·미세먼지)가 바뀐다.

| 피자 | 서비스 의미 |
| --- | --- |
| 피자 한 판 | 오늘 알림을 받을 시간대 |
| 조각 | 알림 1회 (3~8조각 중 선택) |
| 피자 종류 | 내 컨디션 (온보딩에서 고르고, 조각마다 바꿀 수 있음) |
| 먹은 조각 | 완료한 스트레칭 |
| 오늘 완성된 피자 | 하루 요약 |
| 휴무 | 통증·저림이 있을 때 추천을 멈추는 장치 |

### 피자 종류 (이름은 미정, 임시로 컨디션 문구만 사용)

| 컨디션 문구 | 비고 |
| --- | --- |
| 어깨가 뻐근해요 | |
| 머리가 굳은 것 같아요 | |
| 눈이 침침해요 | 눈 동작은 직접 큐레이션한 데이터를 쓴다. 효과를 단정하지 않는다 |
| 컨디션이 좋아요 | |
| 허리가 뻐근해요 | 기획 자료의 "허리가 아파요"를 바꿨다. 통증은 휴무로 분리했다 |
| 아파요 (통증·저림) | 휴무. 동작을 추천하지 않는다 |

- 이전 안의 "머리가 아파요"는 쓰지 않는다. 두통은 증상이라 스트레칭을 추천하면 위험할 수 있다.
- 종류를 하루에 하나로 고정하지 않는다. 온보딩에서 고른 종류가 기본값이고, 컨디션이 바뀌면 조각을 열 때 바꿀 수 있다.
- 이름 옆에는 항상 실제 컨디션 문구를 같이 보여 준다.

## 8. 서비스 방식 (MVP 기능 범위)

1. **랜딩과 로그인**: 카피와 함께 메일 주소만 입력해 로그인한다(인증 없음, 12장 리스크 참고). 메일 주소를 처음 쓰면 온보딩으로 간다.
2. **온보딩 페이지** (단계별)
   1. 몇 시부터 몇 시까지 알려줄까요?
   2. 어느 동네에 계세요? (날씨용 도시 선택)
   3. 앱 서비스는 준비 중이에요, 메일로 알려드릴게요. (앱 출시 안내 수신 선택, 개인정보 동의 필수)
   4. 어떤 피자가 좋을지 선택해봐요. 컨디션에 따라 맞춤 스트레칭을 안내할게요.
   5. 몇 조각으로 잘라줄까요? (3~8회)
3. **알림 시간 규칙**: 입력한 시간대 안에 양 끝을 포함해 균등하게 나눈다(5분 단위 반올림). 종료가 시작보다 이르면 다음 날로 계산한다. 예: 09:00~18:00, 3조각 → 09:00 / 13:30 / 18:00.
4. **알림 메일**: 조각 시각에 메일이 간다. 링크로 들어오면 해당 조각의 스트레칭 화면이 열린다. 수신 거부 링크를 넣는다. 정각보다 5~15분 늦을 수 있다.
5. **오늘의 피자 페이지(메인)**: 일러스트 피자, 먹은 조각과 남은 조각 구분, 다음 조각까지 남은 시간, 날씨 한 줄, "지금 한 조각 먹기".
6. **조각 실행 페이지**
   - 피자 종류와 자세(의자·서서·누워서)를 확인한다.
   - 날씨를 반영해 동작 1개를 보여 준다. 날씨가 나쁘면 실내 동작만, 맑으면 서서 하는 동작을 우선한다.
   - 30초 타이머, "다 먹었어요", "다른 동작", "30분 뒤 다시".
7. **휴무**: 동작을 추천하지 않고 휴식과 전문의 상담을 안내한다.
8. **기록 페이지**: 오늘 완성된 피자, 최근 30일 달력, 연속 일수, 종류별 횟수.

**MVP에서 하지 않는 것**: 챗봇, 생성형 AI, 메일 인증 로그인, 앱 푸시, 근무표 연동.

## 9. 무료 API 활용 방식

| 순서 | API | 역할 |
| --- | --- | --- |
| 메인 | Open-Meteo (날씨·대기질) | 키 없이 호출. 도시 좌표로 현재 날씨, 기온, 미세먼지를 받아 화면 효과와 동작 추천(실내·실외, 안내 문구)에 쓴다 |
| 보조 | API Ninjas Exercises | "다른 동작"을 누르면 피자 종류에 맞는 `muscle`로 호출한다. 항상 `type=stretching`이고, 응답에서 expert·도구 필요·스트레칭이 아닌 동작은 거른다 |
| 데이터 | free-exercise-db에서 고른 로컬 JSON | 기본 동작(한국어, 사진, 자세 태그)과 API 실패 시 대체. 눈 동작은 별도 작성 |

- 파라미터 규칙은 `docs/SPEC.md` 8.1.1에 있다. API Ninjas에는 `shoulders` 부위가 없고 `traps`는 스트레칭이 0건이라서 어깨 피자는 `neck`, `middle_back`, `chest`로 호출한다.
- Open-Meteo 무료는 비상업용이다. 앱을 상업적으로 내놓기 전에 약관을 다시 확인한다.
- API Ninjas 무료 등급은 한 번에 10개까지 받았고(실호출) 상업적 이용이 안 된다. 설명은 영어다.
- 모든 호출은 캐시와 대체 경로를 둔다.

## 10. 출시 전략: 웹으로 수요 확인 → 앱

| 단계 | 하는 일 | 다음 단계로 가는 조건 |
| --- | --- | --- |
| 1. Streamlit 웹 MVP | 로그인, 온보딩, 피자, 조각 실행, 기록. 알림은 메일로 | 테스터 확보, 조각 완료율 확인 |
| 2. 웹 파일럿 (1~2주) | 하루 3조각 달성률, 메일 → 접속 전환, 재방문, 앱 출시 안내 수신 동의율 확인 | 목표치는 파일럿 전에 정함(미정) |
| 3. 앱 MVP | 크로스플랫폼 앱과 로컬 알림 | 7일 리텐션이 건강·피트니스 앱 평균(18.13%) 이상 [E10] |

**메일 알림과 앱 알림의 차이**
- 메일은 앱을 열어 두지 않아도 도착하지만 몇 분 늦을 수 있고 눈에 덜 띈다. 앱 로컬 알림은 정시에 화면을 켠다.
- iOS 웹 푸시는 홈 화면에 추가한 웹 앱에서만 동작하고 [E12], 브라우저 예약 알림 API는 개발이 중단돼 [E13] 웹 푸시 대신 메일을 택했다.
- Streamlit은 서버에서 화면을 다시 그리는 구조라 앱 안에서 스케줄을 돌릴 수 없다. 그래서 메일 발송은 GitHub Actions가 맡는다.

## 12. 리스크와 미결 사항

**리스크**
- 알림 피로: 알림이 너무 많으면 39%가 알림을 끈다 [E9]
- 건강 안내 책임: 진단 금지, 의료 고지, 휴무(아파요) 종류로 대응
- 워치 기본 알림과의 차별화
- API Ninjas 무료 한도와 영어 설명
- 메일 주소만으로 로그인하므로 남의 주소로도 들어올 수 있다. 저장하는 정보가 스트레칭 기록뿐이라는 전제로 MVP에서 받아들이고, 파일럿 뒤 메일 인증 코드로 올린다
- 메일 발송 지연: GitHub Actions cron은 5~15분 늦을 수 있고, Gmail 개인 계정은 하루 발송 한도가 있다
- 개인정보: 메일 주소를 수집하므로 동의, 수신 거부, 파일럿 종료 뒤 파기 방침이 필요하다. 앱 출시 안내는 별도 선택 동의로 받는다
- 날씨 데이터는 비상업용 무료이고 대기질은 모델 추정치다. 화면에 "참고용"으로 표시한다

**결정된 사항**
- 자세 필터(의자·서서·누워서)를 넣는다
- 수요·기록 저장소는 Google Sheets다
- 로그인은 메일 주소 입력만 한다
- 알림은 메일(GitHub Actions cron + Gmail SMTP)로 보낸다
- 날씨로 화면 효과와 동작 추천을 바꾼다

**미결 사항**
- [ ] 피자 종류 최종 이름 (사용자 검토 중)
- [ ] 눈 동작(`data/eyes_ko.json`) 내용과 검수
- [ ] 영어 설명(API Ninjas)을 원문 그대로 보여 줄지, 한국어 요약을 따로 둘지
- [ ] 파일럿 목표치
